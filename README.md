# Workshop_UACh-PSU_Genomics
Archivos FASTQ para el curso "Introducción a la Genómica Bacteriana". Cada archivo corresponde a un genoma asignado a un estudiante. Se utilizarán en Google Colab para ensamblado con Flye, anotación con Bakta, evaluación con BUSCO, ANI, árboles filogenéticos y pan-genómica con Panaroo.
